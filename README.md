
# Stack-Based Allocator

An exploration of stack-based memory allocation and last-in, first-out (LIFO) memory management.

## Overview

Stack allocators manage memory in allocation order, allowing memory to be reclaimed by moving backwards through the allocated region.

## Concepts

- Stack-based memory management
- LIFO allocation and deallocation
- Pointer manipulation
- Low-level memory organisation

## Purpose

Developed to better understand how memory allocation strategies can take advantage of predictable allocation patterns.
